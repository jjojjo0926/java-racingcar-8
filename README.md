# java-racingcar-precourse

## 자동차 경주

---

# 1. 이름이 부여 가능한 자동차 객체 구현
    1) 자동차의 이름은 5자 이하
    2) 쉼표를 기준으로만 구분
    3) 잘못된 값을 입력할 경우 IllegalArgumentException 발생

# 2. 주어진 횟수, K번 동안 N대의 자동차를 전진 또는 멈출 경주 객체 구현
    1) 무작위 값을 구하고 4 이상인 경우에만 전진

# 3. 경주 객체의 자동차 경주 상황 출력 기능
    1) 경주 중 차수별 상황 출력
    2) K번 경주 후 우승자 출력
